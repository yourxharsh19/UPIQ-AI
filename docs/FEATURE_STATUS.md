# Feature status

Statuses describe repository evidence, not a guarantee of production readiness. “Implemented” means a meaningful frontend/backend path is present; runtime deployment and end-to-end behavior were not re-tested as part of this documentation update.

| Feature | Status | Evidence and scope |
|---|---|---|
| Authentication and session handling | **Implemented** | Backend JWT login/register and protected requests; frontend auth helper, demo separation, token cleanup and 401 event handling. `backend/src/main/java/com/upiq/auth/controller/AuthController.java`; `frontend/src/utils/authFlow.js`; `frontend/src/services/api.js`; `frontend/src/context/FinancialContext.jsx`. Registration page exists but active `App.jsx` does not render a registration view. Google login is unavailable. |
| Dashboard | **Implemented** | Backend computes authenticated user's latest-month financial summary; frontend also renders separate client-side widgets. `backend/src/main/java/com/upiq/financial/dashboard/`; `frontend/src/pages/Dashboard.jsx`; `frontend/src/context/FinancialContext.jsx`. Widget data consistency should be checked with real account data. |
| Expense/transaction tracking | **Implemented** | Authenticated transaction CRUD/filter endpoints and frontend transaction workflow. `backend/src/main/java/com/upiq/transaction/controller/TransactionController.java`; `frontend/src/pages/Transactions.jsx`; `frontend/src/hooks/useTransactions.js`. |
| Statement import | **Partially implemented** | PDF upload, preview and save workflow; backend parser supports PDF/CSV, while the current page accepts PDF. Text extraction is not OCR. `frontend/src/pages/UploadPDF.jsx`; `frontend/src/components/transactions/StatementUploadModal.jsx`; `backend/src/main/java/com/upiq/pdf/`. |
| Budgets | **Partially implemented** | Budget context/local storage and UI components exist, but the active `App.jsx` does not mount `BudgetProvider`; the active Insights screen reads `FinancialContext` budget state. No backend persistence. `frontend/src/context/BudgetContext.jsx`; `frontend/src/pages/Insights.jsx`; `frontend/src/hooks/useAIBudget.js`. |
| Categories and deterministic categorization | **Partially implemented** | Category CRUD API and deterministic auto-categorization exist; `Categories.jsx` is not reachable in the active `App.jsx` navigation. Transaction category filtering/categorization remains available. `backend/src/main/java/com/upiq/category/`; `backend/src/main/java/com/upiq/transaction/categorization/`; `frontend/src/pages/Categories.jsx`; `frontend/src/App.jsx`. |
| Reports / analytics | **Partially implemented** | Authenticated report PDF API and deterministic calculations exist. Frontend report archive/preview uses report state and contains placeholder summary claims; it is not an implemented report-history service. `backend/src/main/java/com/upiq/financial/report/`; `backend/src/main/java/com/upiq/research/calculation/`; `frontend/src/pages/Reports.jsx`; `frontend/src/data/initialState.js`. |
| Financial Assistant / chat with expenses | **Partially implemented** | Bounded backend intent dispatch, deterministic calculation and grounded System C/Ollama path exist. The frontend falls back to heuristic replies containing fixed example claims if the API fails or returns no answer. `backend/src/main/java/com/upiq/financial/chat/`; `backend/src/main/java/com/upiq/research/`; `frontend/src/pages/AIAssistant.jsx`. |
| Budget prediction | **Partially implemented** | Insights UI displays a spending-velocity projection derived by frontend hook logic; no prediction model/service or backend budget persistence found. `frontend/src/pages/Insights.jsx`; `frontend/src/hooks/useAIBudget.js`. |
| Investment suggestions | **Not implemented** | A presentation component exists, but initial investment state is empty and no supporting backend/service was found. `frontend/src/components/insights/InvestmentSuggestions.jsx`; `frontend/src/data/initialState.js`. |
| Fraud detection | **Not implemented** | Fraud drawer/alerts are UI state only; initial alerts are empty and no detection service/API was found. Assistant fallback can present invented fraud examples. `frontend/src/data/initialState.js`; `frontend/src/context/FinancialContext.jsx`; `frontend/src/pages/AIAssistant.jsx`. |
| Voice assistant | **Needs verification** | Browser speech input hook and speech UI exist; browser compatibility and full user workflow were not exercised. `frontend/src/hooks/useVoiceInput.js`; `frontend/src/pages/AIAssistant.jsx`. |
| Notifications | **Partially implemented** | In-app toast state/rendering exists. No persistent, push, or backend notification feature found. `frontend/src/context/FinancialContext.jsx`; `frontend/src/components/common/ToastContainer.jsx`. |
| Admin functionality | **Partially implemented** | Admin page and navigation guard exist, but metrics are initialized as sample/static values and no admin management API/authorization workflow is present. UI role selection is not proof of backend privileges. `frontend/src/pages/Admin.jsx`; `frontend/src/data/initialState.js`; `frontend/src/App.jsx`; `backend/src/main/java/com/upiq/auth/controller/UserController.java`. |
| Research A/B/C foundation and runner | **Implemented** | Typed cases/inputs/results, three adapters, shared Ollama boundary, benchmark data, opt-in runner/result writer exist. No scoring or statistical evaluation. `backend/src/main/java/com/upiq/research/`; `backend/src/main/resources/research/`. |
| Research evaluation metrics/statistics | **Not implemented** | No answer scoring, accuracy/hallucination metric, or statistical analysis was found. |

## Active navigation

`frontend/src/App.jsx` maps `FinancialContext.activeTab` to Dashboard, Transactions, AI Assistant, Insights (also the `security` tab), Reports, Profile, and conditionally Admin. `Home` and `Login` are view states. `Register` and `Categories` components are not mapped in this active switch. React Router is present as a dependency but is not the current navigation mechanism.
